```javascript
  onTransferPress: function,
  onDTMFPress: function,
  onHoldPress: function,
  onUnHoldPress: function
}
```

**Buttons:**
| Button | Condition |
|--------|-----------|
| Mute | !call.isMuted() |
| Unmute | call.isMuted() |
| Hold | !call.isHeld() |
| Unhold | call.isHeld() |
| Speaker | !call.isSpeaker() |
| Earpiece | call.isSpeaker() |
| DTMF | Always visible |
| Transfer | Always visible |
| Add | Always visible |
| Chat | Always visible |

**Visual:**
- 40% screen height
