## Module Overview

**Call UI Presentation** provides the visual interface for active calls, including animated state transitions, call information display, user controls, and modal dialogs for advanced features.

## Visual Requirements

### VR-1: Call Screen Layout

**Description:** The call screen must display call information in a vertically stacked, animated layout.

**Layout Proportions:**
| Component | Height | Purpose |
|-----------|--------|---------|
| CallParallelInfo | Dynamic | Show multiple simultaneous calls |
| CallAvatar | 30% | Caller avatar/photo |
| CallInfo | 12% | Caller name, number |
| CallState | 8% | Call duration, status |
| CallActions | 40% | Mute, hold, speaker, etc. |
| CallControls | 64px | Answer/hangup buttons |

**Visual Style:**
- Background: Linear gradient `#2a5743` → `#14456f` (teal to blue)
- Full-screen layout
- Responsive to screen dimensions

**Source:** `src/screens/CallScreen/index.js`, `src/screens/CallScreen/anim.js`

---

### VR-2: Animated State Transitions

**Description:** UI components must animate smoothly when call state changes.

**Animation Behavior:**

| Transition | Avatar | Info | State | Actions |
|------------|--------|------|-------|---------|
| INCOMING → ACTIVE | Fade out, slide up | Stay visible | Stay visible | Fade in, slide up |
| ACTIVE → DISCONNECTED | Stay hidden | Stay visible | Stay visible | Fade out, slide down |
| INCOMING (initial) | Fade in, slide down | Fade in | Fade in | Stay hidden |

**Animation Type:** `Animated.parallel()` - all components animate simultaneously.

**Duration:** Default React Native Animated timing (300-500ms).

**Source:** `src/screens/CallScreen/anim.js` → `animateCallState()`

**Display Priority:**

**Text Formatting:**

- Centered alignment

### VR-4: Call Duration Display

**Description:** Show real-time call duration in MM:SS or HH:MM:SS format.

**Display Requirements:**
- Update frequency: On every render (live calculation)
- Format: `MM:SS` for calls < 1 hour, `HH:MM:SS` for longer
- Zero-padding: Always show two digits per segment
- Examples: `00:00`, `01:05`, `01:01:01`

**Source:** `src/components/call/CallState`, `src/modules/call.js`

## Interaction Requirements

### IR-1: Call Answer Flow

```
INCOMING state detected
    ↓
IncomingCallModal appears
    ↓
User taps Answer
    ↓
onCallAnswer callback fired
    ↓
Animation: INCOMING → ACTIVE
    ↓
Modal dismissed, CallActions visible
```

---

### IR-2: Call Hangup Flow

```
User taps Hangup
    ↓
onCallHangup callback fired
    ↓
Animation: ACTIVE → DISCONNECTED
    ↓
CallActions hidden
    ↓
Navigation: Return to previous screen (after 3s delay)
```

---

### IR-3: DTMF Input Flow

```
User taps DTMF button
    ↓
DtmfModal appears
    ↓
User taps keypad digit
    ↓
onCallDtmf callback fired with digit
    ↓
DTMF tone sent via endpoint
    ↓
User closes modal or call ends
```

---

### IR-4: Call Transfer Flow

```
User taps Transfer button
    ↓
TransferModal appears
    ↓
User selects:
  - Attendant: Choose existing call
  - Blind: Enter number
    ↓
onCallAttendantTransfer or onCallBlindTransfer callback fired
    ↓
Modal dismissed
    ↓
Transfer initiated via endpoint
```
