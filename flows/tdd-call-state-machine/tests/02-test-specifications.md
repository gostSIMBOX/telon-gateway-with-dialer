## Test 2: Duration Calculation

### Test: Calculate Total Duration

```javascript
test('should calculate total duration correctly', () => {
  const now = Math.round(new Date().getTime() / 1000);
  const creationTime = now - 60; // 60 seconds ago
  
  const call = new Call({
    creationTime: creationTime,
    _constructionTime: creationTime
  });
  
  const duration = call.getTotalDuration();
  expect(duration).toBeGreaterThanOrEqual(60);
  expect(duration).toBeLessThan(62); // Allow 1s tolerance
});
```

**Expected:** ✅ PASS

---

### Test: Calculate Connect Duration (Connected Call)

```javascript
test('should calculate connect duration for active call', () => {
  const now = Math.round(new Date().getTime() / 1000);
  const connectTime = now - 30; // Connected 30 seconds ago
  
  const call = new Call({
    connectTime: connectTime,
    _connectDuration: 0,
    _state: 'PJSIP_INV_STATE_CONFIRMED',
    _constructionTime: now
  });
  
  const duration = call.getConnectDuration();
  expect(duration).toBeGreaterThanOrEqual(0);
});
```

**Expected:** ✅ PASS

## Test 7: Integration Tests

### Test: Full Call Lifecycle

```javascript
test('should handle full call lifecycle', () => {
  // Incoming call
  const incoming = new Call({
    remoteUri: 'tel:+79001234567',
    state: 'PJSIP_INV_STATE_INCOMING'
  });
  
  expect(incoming.isTerminated()).toBe(false);
  expect(incoming.getRemoteNumber()).toBe('+79001234567');
  
  // Call answered
  incoming._state = 'PJSIP_INV_STATE_CONFIRMED';
  expect(incoming.isTerminated()).toBe(false);
  
  // Call ended
  incoming._state = 'PJSIP_INV_STATE_DISCONNECTED';
  expect(incoming.isTerminated()).toBe(true);
});
```

**Expected:** ✅ PASS
